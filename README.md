# Shareef Technologies Website

Official website for **Shareef Technologies**, an independent software studio founded by **Musah Shareef** in Ghana.

## Product Spotlight: Gist
Featuring **Gist**, a real-time university campus social platform built with React Native, Expo SDK 57, Firebase, and native mobile widgets for Android (AppWidgets) & iOS (WidgetKit).

## Getting Started

Install dependencies:
```bash
npm install
```

Run local dev server:
```bash
npm run dev
```

Build for production:
```bash
npm run build
```
